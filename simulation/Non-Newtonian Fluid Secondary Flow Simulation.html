The secondary flow is governed by a differential equation involving a single parameter α which can be explicitly expressed in terms of the non-Newtonian parameters in each constitutive equation.

For a given value of α, all three fluids have identical secondary flows. The models differ only in their normal stress components.

Constitutive Equation Comparison

Rivlin-Ericksen (R-E)

T = -pI + 2ηE + Φ₂D + 4Φ₃E²

Includes cross-viscosity and viscoelasticity through acceleration-gradient tensor.

Can be distinguished from other models by studying normal stress components.

Oldroyd (O)

S + τ₁(δS/δt - SE - ES) + μ₀(tr S)E = 2η[E + τ₂(δE/δt - 2E²)]

Incorporates elasticity through relaxation times τ₁ and τ₂.

Indistinguishable from Walters fluid for same α value in secondary flows.

Walters (W)

S = 2∫[N(τ)/τ]∫exp((t'-t)/τ)(∂x/∂x')E(x',t') dt' dτ

Memory effects through integral over relaxation time spectrum.

Indistinguishable from Oldroyd fluid for same α value in secondary flows.
