How This Visual Proof Works

The cube with side length (a+b) has a volume of (a+b)³.

When we break this cube apart, we find:

  • One cube with side length a (volume = a³)
  • One cube with side length b (volume = b³)
  • Three rectangular prisms with dimensions a×a×b (volume = 3a²b)
  • Three rectangular prisms with dimensions a×b×b (volume = 3ab²)

These pieces can be rearranged to form the original cube, proving that:

(a + b)³ = a³ + 3a²b + 3ab² + b³

Use the sliders to change the values of a and b and see how the volumes change while maintaining the identity.
