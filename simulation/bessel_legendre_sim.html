🌊 Bessel's Functions Jn(x)

🎯 Legendre's Polynomials Pn(x)

📐 Bessel's Equation

x²y'' + xy' + (x² - n²)y = 0

Solutions are called Bessel functions of the first kind Jn(x)

🎓 Applications

  • Vibrating circular membranes
  • Heat conduction in cylinders
  • Wave propagation
  • Signal processing

🔄 Recurrence Relations

Jn-1(x) + Jn+1(x) = (2n/x)Jn(x)
Jn-1(x) - Jn+1(x) = 2J'n(x)

📐 Legendre's Equation

(1-x²)y'' - 2xy' + n(n+1)y = 0

Solutions are Legendre polynomials Pn(x) for integer n

🎓 Applications

  • Spherical harmonics
  • Gravitational potentials
  • Electrostatics
  • Quantum mechanics

🧮 Rodrigue's Formula

Pn(x) = (1/2ⁿn!) dⁿ/dxⁿ[(x²-1)ⁿ]

Generates Legendre polynomials of any order

🔍 Orthogonality

Bessel Functions:

∫₀¹ xJn(αx)Jn(βx)dx = 0 (α ≠ β)

Legendre Polynomials:

∫₋₁¹ Pm(x)Pn(x)dx = 0 (m ≠ n)

📊 Generating Functions

Legendre:

(1-2xt+t²)^(-1/2) = Σ Pn(x)tⁿ

Generates all Legendre polynomials at once

💡 Key Properties

  • Pn(1) = 1 for all n
  • Pn(-x) = (-1)ⁿPn(x)
  • J-n(x) = (-1)ⁿJn(x) for integer n
  • Both satisfy recurrence relations
