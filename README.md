# 📘 S.M. Yusuf Calculus & Analytic Geometry Simulations

Interactive mathematical visualizations, simulations, and educational tools based on the classic textbook **S.M. Yusuf — Calculus & Analytic Geometry**.

This project turns traditional mathematical concepts into dynamic, interactive, and visually intuitive learning experiences using modern web technologies.

**[Launch the site »](index.html)** &nbsp;|&nbsp; **[Featured: Fourier Series Simulator »](simulation/fourier_series_simulator.html)**

---

## 🌟 Project Vision

Mathematics is best understood when learners can **see**, **explore**, and **interact** with concepts.

This repository provides:

* Interactive calculus simulations
* Analytic geometry explorers
* Polar coordinate visualizations
* Quadric surface renderers
* Multiple integral demonstrations
* Curve tracing tools
* Numerical quadrature explorers
* Dynamic theorem visualizations
* Educational SVG and Canvas applications
* Browser-based mathematical laboratories

The goal is to build a complete digital companion to the S.M. Yusuf textbook for students, teachers, and self-learners — plus a growing library of standalone simulations that go beyond it.

This project is complemented by two specialized AI models for generating mathematical graphics and visual explanations.

**[Hugging Face — Qwen-GeoGebra-Coder-7B](https://huggingface.co/Khurram123/Qwen-GeoGebra-Coder-7B)**

Converts natural-language mathematical descriptions into GeoGebra-compatible visualizations and geometry constructions — combining mathematical reasoning with automated geometry generation. Capabilities include GeoGebra code generation, 2D/3D geometry construction, coordinate and analytic geometry, and educational visualization.
