1 What is a Function?

A function $f$ from a set $A$ (the domain) to a set $B$ (the codomain) is a rule that assigns to every element $x\in A$ exactly one element $f(x)\in B$.

$$f:A\to B,\qquad x\mapsto f(x)$$

Think of it as a machine: feed it an input, and it produces a unique output.

Key rule: Each input must produce exactly one output. The vertical line test on a graph captures this: if any vertical line crosses the curve more than once, it is not a function.

2 Types by Mapping: Injective, Surjective, Bijective

Functions can be classified by how they relate domain elements to codomain elements.

Injective (One-to-One)
Surjective (Onto)
Bijective
Neither

Injective (One-to-One)

Every element of the domain maps to a distinct element of the codomain. No two different inputs share the same output.

$$\forall x_1,x_2\in A:\; f(x_1)=f(x_2)\Rightarrow x_1=x_2$$

Horizontal line test: Every horizontal line intersects the graph at most once.

4 Even & Odd Functions — Symmetry

Even Function

Symmetric about the y-axis.

$$f(-x)=f(x)$$

Examples: $x^2,\;\cos x,\;|x|$.

Odd Function

Symmetric about the origin (180° rotation).

$$f(-x)=-f(x)$$

Examples: $x^3,\;\sin x,\;x$.

6 Composition of Functions

Given $f$ and $g$, their composition $(f\circ g)(x)=f(g(x))$ applies $g$ first, then $f$.

f(x) g(x) (f∘g)(x)
Trace the chain: at $x=1$, $g(1)=2$, then $f(g(1))=f(2)=4$. The green curve is the result of feeding every $x$ through this two-stage pipeline.

7 Inverse Functions

A function $f$ has an inverse $f^{-1}$ if and only if it is bijective. The graph of $f^{-1}$ is the reflection of $f$ across the line $y=x$.

f(x) f⁻¹(x) y = x
$$f^{-1}(f(x))=x\quad\text{and}\quad f(f^{-1}(y))=y$$

8 Periodic & Piecewise Functions

Periodic Function

A function is periodic with period $T$ if $f(x+T)=f(x)$ for all $x$.

$$\sin(x+2\pi)=\sin x$$

Piecewise Function

Different formulas on different parts of the domain.

$$f(x)=\begin{cases} -x & x<0\\ x^2 & 0\le x<2\\ 4-(x-2) & x\ge 2\end{cases}$$
