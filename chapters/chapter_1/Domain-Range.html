Domain & Range: Core Algebraic Rules

Systematic determination of the domain and range of real-valued functions.

1 Rational Functions

For $f(x) = \dfrac{P(x)}{Q(x)}$, exclude values where the denominator is zero:

$$Q(x) \neq 0 \quad \Longrightarrow \quad \text{Domain} = \mathbb{R} \setminus \{x \mid Q(x)=0\}$$

Example: $f(x)=\frac{x+1}{x-2}$ → Domain: $\mathbb{R}\setminus\{2\}$, i.e. $(-\infty,2)\cup(2,\infty)$

2 Even Radical Functions

For $\sqrt[2n]{g(x)}$, the radicand must be non-negative:

$$g(x) \geq 0 \quad \Longrightarrow \quad \text{Domain} = \{x \in \mathbb{R} \mid g(x) \geq 0\}$$

Example: $f(x)=\sqrt{16-x^2}$ → $16-x^2 \geq 0$ → $x \in [-4, 4]$

3 Logarithmic Functions

For $\log_a(g(x))$, the argument must be strictly positive:

$$g(x) > 0 \quad \Longrightarrow \quad \text{Domain} = \{x \in \mathbb{R} \mid g(x) > 0\}$$

Example: $f(x)=\ln(x-3)$ → $x-3 > 0$ → $x \in (3, \infty)$

4 Inverse Trigonometric Functions

For $\arcsin(g(x))$ and $\arccos(g(x))$, restrict argument to $[-1, 1]$:

$$-1 \leq g(x) \leq 1$$

$\arcsin(x)$: domain $[-1, 1]$, range $[-\pi/2, \pi/2]$. $\arccos(x)$: domain $[-1, 1]$, range $[0, \pi]$.

5 Piecewise & Absolute Value

For piecewise definitions, the domain is the union of sub-domains:

$$\text{Domain}(f) = D_1 \cup D_2 \cup \dots \cup D_n$$

For $|g(x)|$, domain equals domain of $g$; range is always $\subseteq [0, \infty)$.
