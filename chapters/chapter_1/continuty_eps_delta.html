Function f(x)

📊 Epsilon (ε) Control

ε represents the tolerance around f(c). For any chosen ε > 0, we must find a δ.

📏 Delta (δ) Control

δ is the distance around c that guarantees |f(x) - f(c)| < ε

🎯 Point c

Formal Definition

∀ ε > 0, ∃ δ > 0 :
|x - c| < δ ⇒ |f(x) - f(c)| < ε

"For every ε > 0, there exists δ > 0 such that if x is within δ of c, then f(x) is within ε of f(c)"
