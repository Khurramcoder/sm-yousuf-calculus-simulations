Field Axioms: Addition & Multiplication

The real numbers $\mathbb{R}$ form a complete ordered field satisfying the following axioms:

Addition Axioms

A1: Closure under Addition
$$\forall a,b \in \mathbb{R}: a + b \in \mathbb{R}$$
A2: Commutativity
$$a + b = b + a$$
A3: Associativity
$$(a + b) + c = a + (b + c)$$
A4: Additive Identity
$$\exists 0 \in \mathbb{R}: a + 0 = a$$
A5: Additive Inverse
$$\forall a \in \mathbb{R}, \exists -a: a + (-a) = 0$$

Multiplication Axioms

M1: Closure under Multiplication
$$\forall a,b \in \mathbb{R}: a \cdot b \in \mathbb{R}$$
M2: Commutativity
$$a \cdot b = b \cdot a$$
M3: Associativity
$$(a \cdot b) \cdot c = a \cdot (b \cdot c)$$
M4: Multiplicative Identity
$$\exists 1 \in \mathbb{R}, 1 \neq 0: a \cdot 1 = a$$
M5: Multiplicative Inverse
$$\forall a \neq 0, \exists a^{-1}: a \cdot a^{-1} = 1$$
D: Distributive Law
$$a \cdot (b + c) = a \cdot b + a \cdot c$$

Existence of Irrational Numbers

Not all real numbers are rational. The set $\mathbb{R} \setminus \mathbb{Q}$ is uncountably infinite.

Theorem: $\sqrt{2}$ is Irrational

By contradiction: Assume $\sqrt{2} = \frac{p}{q}$ where $p, q \in \mathbb{Z}$ are coprime.

Then $2q^2 = p^2$, implying $p$ is even. Let $p = 2k$.

Then $2q^2 = 4k^2 \Rightarrow q^2 = 2k^2$, so $q$ is also even.

Contradiction: $p$ and $q$ share a common factor of 2.

Key Properties
  • $\mathbb{Q}$ is countable, $\mathbb{R}$ is uncountable
  • Measure of $\mathbb{Q}$ is 0, measure of irrationals is infinite
  • Both sets are dense in $\mathbb{R}$

Order Properties of $\mathbb{R}$

The real numbers form a totally ordered field with the following properties:

O1: Trichotomy Law
$$\forall a,b \in \mathbb{R}: \text{exactly one holds: } a < b, a = b, a > b$$
O2: Transitivity
$$a < b \text{ and } b < c \Rightarrow a < c$$
O3: Translation Invariance
$$a < b \Rightarrow a + c < b + c$$
O4: Multiplication by Positive
$$a < b \text{ and } c > 0 \Rightarrow ac < bc$$
O5: Multiplication by Negative
$$a < b \text{ and } c < 0 \Rightarrow ac > bc$$

Archimedean Property
$$\forall x \in \mathbb{R}, \exists n \in \mathbb{N}: n > x$$

Absolute Value Properties

The absolute value $|x|$ represents the distance from $x$ to 0 on the real line.

Value of x: 3

$|x| = 3$ (distance from 0)

Definition
$$|x| = \begin{cases} x & \text{if } x \geq 0 \\ -x & \text{if } x < 0 \end{cases}$$
Triangle Inequality
$$|a + b| \leq |a| + |b|$$
Reverse Triangle Inequality
$$||a| - |b|| \leq |a - b|$$
Multiplicative Property
$$|ab| = |a||b|$$

Completeness Property

This is the defining property that distinguishes $\mathbb{R}$ from $\mathbb{Q}$. Every non-empty set of real numbers that is bounded above has a least upper bound (supremum).

Least Upper Bound Property

If $S \subseteq \mathbb{R}$ is non-empty and bounded above, then $\sup(S)$ exists in $\mathbb{R}$.

Greatest Lower Bound
$$\inf(S) = -\sup(-S)$$
Nested Intervals Theorem

If $[a_1, b_1] \supseteq [a_2, b_2] \supseteq \cdots$ and $\lim_{n\to\infty}(b_n - a_n) = 0$, then $\bigcap_{n=1}^{\infty}[a_n, b_n]$ contains exactly one point.

Cauchy Completeness
$$\text{Every Cauchy sequence in } \mathbb{R} \text{ converges}$$
