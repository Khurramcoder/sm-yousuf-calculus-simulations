What are Indeterminate Forms?

Indeterminate forms are expressions that arise when evaluating limits, where the direct substitution leads to an undefined or ambiguous result. These forms require special techniques (like L'Hôpital's Rule, algebraic manipulation, or series expansion) to evaluate the actual limit.

Common indeterminate forms: 0/0, ∞/∞, 0·, ∞-∞, 0⁰, 1^∞, ∞⁰

Form 0/0

When both numerator and denominator approach zero

🎮 Interactive Simulation

x = 1.000
limx→1 (x²-1)/(x-1) = 2
️ At x = 1: Direct substitution gives 0/0 (undefined), but the limit exists!

Mathematical Explanation

Example: limx→1 (x²-1)/(x-1)
1 Direct substitution: (1²-1)/(1-1) = 0/0 (Indeterminate!)
2 Factor numerator: x²-1 = (x-1)(x+1)
3 Cancel common factor: limx→1 [(x-1)(x+1)]/(x-1) = limx→1 (x+1)
4 Evaluate: 1+1 = 2
Using L'Hôpital's Rule:
1 Differentiate numerator and denominator:
2 limx→1 (2x)/(1) = 2(1)/1 = 2

Form /∞

When both numerator and denominator approach infinity

🎮 Interactive Simulation

x = 10.0
limx→ (3x²+2x)/(x²+1) = 3
✓ Result: As x→∞, both → ∞, but the ratio approaches 3

📐 Mathematical Explanation

Example: limx→∞ (3x²+2x)/(x²+1)
1 Direct substitution: ∞/∞ (Indeterminate!)
2 Divide by highest power (x²):
3 limx→∞ (3 + 2/x)/(1 + 1/x²) = (3+0)/(1+0) = 3

Form 0·∞

When one factor approaches 0 and the other approaches ∞

🎮 Interactive Simulation

x = 0.10
limx→0⁺ x·ln(x) = 0
⚠️ Challenge: 0 × ∞ can be 0, , or any real number depending on which "wins"

📐 Mathematical Explanation

Example: limx→0⁺ x·ln(x)
1 Rewrite as fraction: limx→0⁺ ln(x)/(1/x) = -∞/∞
2 Apply L'Hôpital's Rule:
3 limx→0⁺ (1/x)/(-1/x²) = limx→0⁺ (-x) = 0

Form ∞-∞

When two terms both approach infinity but with opposite signs

🎮 Interactive Simulation

x = 10.0
limx→∞ (√(x²+x) - x) = 1/2

📐 Mathematical Explanation

Example: limx→∞ (√(x²+x) - x)
1 Multiply by conjugate:
2 limx→∞ [(√(x²+x) - x)(√(x²+x) + x)]/(√(x²+x) + x)
3 = limx→∞ (x²+x-x²)/(√(x²+x) + x) = limx→∞ x/(√(x²+x) + x)
4 Divide by x: limx→∞ 1/(√(1+1/x) + 1) = 1/(1+1) = 1/2

Form 0⁰

When base approaches 0 and exponent approaches 0

🎮 Interactive Simulation

x = 0.100
limx→0⁺ x^x = 1
️ Note: 0 is indeterminate but often defined as 1 in combinatorics

📐 Mathematical Explanation

Example: limx→0⁺ x^x
1 Take natural log: Let y = x^x, then ln(y) = x·ln(x)
2 limx→0⁺ x·ln(x) = 0 (from previous form)
3 So limx→0⁺ ln(y) = 0, therefore limx→0⁺ y = e = 1

Form 1^∞

When base approaches 1 and exponent approaches ∞

🎮 Interactive Simulation

x = 100
limx→∞ (1 + 1/x)^x = e ≈ 2.718
✓ Famous limit: This is the definition of e!

📐 Mathematical Explanation

Example: limx→∞ (1 + 1/x)^x
1 Take natural log: Let y = (1 + 1/x)^x
2 ln(y) = x·ln(1 + 1/x) = ln(1 + 1/x)/(1/x)
3 L'Hôpital's Rule: limx→ [1/(1+1/x)·(-1/x²)]/(-1/x²) = limx→∞ 1/(1+1/x) = 1
4 So limx→∞ y = e¹ = e

Form ∞⁰

When base approaches ∞ and exponent approaches 0

🎮 Interactive Simulation

x = 10.0
limx→∞ x^(1/x) = 1

📐 Mathematical Explanation

Example: limx→∞ x^(1/x)
1 Take natural log: Let y = x^(1/x), then ln(y) = (1/x)·ln(x) = ln(x)/x
2 L'Hôpital's Rule: limx→∞ (1/x)/1 = limx→∞ 1/x = 0
3 So limx→∞ y = e⁰ = 1
