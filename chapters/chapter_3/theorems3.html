Theorem 1 Rolle's Theorem

📜 Statement

Let f be a function satisfying:
  • Condition 1: f is continuous on the closed interval [a, b]
  • Condition 2: f is differentiable on the open interval (a, b)
  • Condition 3: f(a) = f(b)
Then there exists at least one point c ∈ (a, b) such that:
f′(c) = 0

🎨 Geometrical Interpretation

If a smooth curve starts and ends at the same height, then at some point between them, the curve must have a horizontal tangent (slope = 0).

The curve has horizontal tangents at points c₁ and c₂ where f′(c) = 0

💡 Simple Analogy: If you drive from point A to point B and return to the same altitude, at some moment your vertical speed must have been exactly zero (you were neither going up nor down).

🔢 Algebraic Explanation

Since f(a) = f(b), the function's net change over [a, b] is zero:

f(b) − f(a) = 0

By the Extreme Value Theorem, a continuous function on a closed interval attains its maximum and minimum. Since f(a) = f(b):

  • If f is constant → f′(x) = 0 everywhere → any c works.
  • If f is not constant → it must have a maximum or minimum at some interior point c ∈ (a, b).
  • At that interior extremum, since f is differentiable: f′(c) = 0 (by Fermat's Theorem).

📝 Proof

1
Case 1: Suppose f is constant on [a, b]. Then f(x) = k for all x, so f′(x) = 0 for all x ∈ (a, b). Any c ∈ (a, b) satisfies the theorem. ✓
2
Case 2: Suppose f is not constant. Since f(a) = f(b) and f takes some other value, either f attains a value > f(a) or a value < f(a).
3
Since f is continuous on the closed interval [a, b], by the Extreme Value Theorem, f attains both a global maximum M and a global minimum m on [a, b].
4
Since f is not constant and f(a) = f(b), at least one of M or m is attained at some point c ∈ (a, b) (an interior point).
5
At this interior extremum c, since f is differentiable at c, by Fermat's Theorem:
f′(c) = 0
6
Therefore, there exists at least one c ∈ (a, b) such that f′(c) = 0. ∎

✅ Example

Let f(x) = x² − 4x + 3 on [0, 4].

• f(0) = 3 and f(4) = 16 − 16 + 3 = 3 → f(0) = f(4) ✓

• f′(x) = 2x − 4. Set f′(c) = 0 → 2c − 4 = 0 → c = 2 ∈ (0, 4) ✓

▼

Theorem 2 Mean Value Theorem (MVT)

📜 Statement

Let f be a function satisfying:
  • Condition 1: f is continuous on [a, b]
  • Condition 2: f is differentiable on (a, b)
Then there exists at least one point c ∈ (a, b) such that:
f′(c) = f(b) − f(a)⁄b − a

That is, the instantaneous rate of change at c equals the average rate of change over [a, b].

🎨 Geometrical Interpretation

There exists a point c on the curve where the tangent line is parallel to the secant line connecting (a, f(a)) and (b, f(b)).

The tangent at c is parallel to the chord joining (a, f(a)) and (b, f(b))

💡 Simple Analogy: If you travel 120 km in 2 hours (average speed = 60 km/h), then at some instant your speedometer must have read exactly 60 km/h.

🔢 Algebraic Explanation

The average rate of change of f over [a, b] is:

Average rate = f(b) − f(a)⁄b − a

The MVT guarantees that the instantaneous rate of change (derivative) equals this average at some interior point. It generalizes Rolle's theorem by removing the condition f(a) = f(b).

🔗 Connection to Rolle's Theorem: If f(a) = f(b), then the average rate is 0/(b−a) = 0, and MVT reduces to Rolle's Theorem!

📝 Proof (Using Rolle's Theorem)

The key idea: construct an auxiliary function g(x) that does satisfy g(a) = g(b), then apply Rolle's Theorem to it.

1
Define the secant line through (a, f(a)) and (b, f(b)):
L(x) = f(a) + f(b) − f(a)⁄b − a · (x − a)
2
Define the auxiliary function as the vertical difference between f and the secant line:
g(x) = f(x) − L(x) = f(x) − f(a) − f(b) − f(a)⁄b − a · (x − a)
3
Check Rolle's conditions for g:
  • g is continuous on [a, b] ✓ (difference of continuous functions)
  • g is differentiable on (a, b) ✓
  • g(a) = f(a) − f(a) − 0 = 0 ✓
  • g(b) = f(b) − f(a) − f(b)−f(a)⁄b−a·(b−a) = f(b) − f(a) − (f(b)−f(a)) = 0 ✓
So g(a) = g(b) = 0.
4
By Rolle's Theorem applied to g, there exists c ∈ (a, b) such that:
g′(c) = 0
5
Compute g′(x):
g′(x) = f′(x) − f(b) − f(a)⁄b − a
Setting g′(c) = 0:
f′(c) − f(b) − f(a)⁄b − a = 0
6
Therefore:
f′(c) = f(b) − f(a)⁄b − a    ∎

✅ Example

Let f(x) = x³ on [1, 3].

• Average rate: f(3)−f(1)⁄3−1 = 27−1⁄2 = 13

• f′(x) = 3x². Set 3c² = 13 → c = √(13/3) ≈ 2.08 ∈ (1, 3) ✓

▼

Theorem 3 Cauchy's Mean Value Theorem

📜 Statement

Let f and g be two functions satisfying:
  • Condition 1: f and g are continuous on [a, b]
  • Condition 2: f and g are differentiable on (a, b)
  • Condition 3: g′(x) ≠ 0 for all x ∈ (a, b)
Then there exists at least one point c ∈ (a, b) such that:
f(b) − f(a)⁄g(b) − g(a) = f′(c)⁄g′(c)
⚠️ Note: Condition 3 ensures g(b) ≠ g(a) (by Rolle's theorem, if g(b)=g(a) then g′(c)=0 somewhere, contradicting condition 3). So the denominator is never zero.

🎨 Geometrical Interpretation

Consider the parametric curve (g(t), f(t)) for t ∈ [a, b] in the XY-plane. This traces a curve from point A = (g(a), f(a)) to point B = (g(b), f(b)).

Cauchy's MVT says: there exists a point on this parametric curve where the tangent is parallel to the chord AB.

Parametric curve (g(t), f(t)) — tangent at C is parallel to chord AB

🔢 Algebraic Explanation

The ratio f(b)−f(a)⁄g(b)−g(a) compares how f and g change relative to each other over [a, b].

Cauchy's MVT says that at some point c, the ratio of their instantaneous rates of change f′(c)⁄g′(c) equals this overall relative change.

🔗 Special Cases:
  • If g(x) = x → g′(x) = 1 → reduces to the Mean Value Theorem
  • If g(x) = x AND f(a) = f(b) → reduces to Rolle's Theorem

📝 Proof (Using Rolle's Theorem)

Again, we construct a clever auxiliary function and apply Rolle's Theorem.

1
Define the auxiliary function:
h(x) = [f(b) − f(a)] · g(x) − [g(b) − g(a)] · f(x)

This is a linear combination of f and g designed so that h(a) = h(b).

2
Verify h(a) = h(b):
h(a) = [f(b)−f(a)]·g(a) − [g(b)−g(a)]·f(a) = f(b)g(a) − f(a)g(a) − g(b)f(a) + g(a)f(a) = f(b)g(a) − g(b)f(a)
h(b) = [f(b)−f(a)]·g(b) − [g(b)−g(a)]·f(b) = f(b)g(b) − f(a)g(b) − g(b)f(b) + g(a)f(b) = g(a)f(b) − f(a)g(b)

Both simplify to f(b)g(a) − f(a)g(b), so h(a) = h(b). ✓

3
Check Rolle's conditions for h:
  • h is continuous on [a, b] ✓
  • h is differentiable on (a, b) ✓
  • h(a) = h(b) ✓ (shown above)
4
By Rolle's Theorem, there exists c ∈ (a, b) such that:
h′(c) = 0
5
Compute h′(x):
h′(x) = [f(b) − f(a)] · g′(x) − [g(b) − g(a)] · f′(x)
Setting h′(c) = 0:
[f(b) − f(a)] · g′(c) = [g(b) − g(a)] · f′(c)
6
Since g′(c) ≠ 0 (Condition 3) and g(b) − g(a) ≠ 0 (proved earlier), we can divide:
f(b) − f(a)⁄g(b) − g(a) = f′(c)⁄g′(c)    ∎

✅ Example

Let f(x) = x² and g(x) = x³ on [1, 2].

• f(2)−f(1)⁄g(2)−g(1) = 4−1⁄8−1 = 3⁄7

• f′(c)⁄g′(c) = 2c⁄3c² = 2⁄3c

• Set equal: 2⁄3c = 3⁄7 → c = 14⁄9 ≈ 1.56 ∈ (1, 2) ✓

🎯 Key Takeaways for Students

  1. Rolle's Theorem is the simplest: equal endpoints → horizontal tangent somewhere.
  2. MVT generalizes Rolle's: the tangent is parallel to the secant line (not necessarily horizontal).
  3. Cauchy's MVT is the most general: works with two functions and parametric curves.
  4. All three proofs rely on the same core idea: construct an auxiliary function satisfying Rolle's conditions, then apply Rolle's Theorem.
  5. Remember: Continuity on the closed interval and differentiability on the open interval are essential — check them first!
